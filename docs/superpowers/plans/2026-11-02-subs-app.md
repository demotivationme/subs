# Subs App (Expo) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the Subs client for iOS, Android and web as one Expo app. It covers auth, the dashboard, subscriptions CRUD, categories, reminders, the in-app inbox, push, and settings, and it consumes the finished Laravel API on branch `dev`.

**Architecture:** An Expo Router app lives in `app/`. Route files in `app/src/app/` are thin re-exports of screen components in `app/src/screens/`, which keeps tests out of the route tree. All server state goes through TanStack Query hooks in `app/src/api/`. Those hooks call one typed `fetch` client that adds the Sanctum bearer token and turns failures into `ApiError` or `NetworkError`. The query cache is persisted, so cached data stays readable offline. A Zustand store holds the session, and `Stack.Protected` guards switch between the `(auth)` and `(app)` route groups. Every user-facing string comes from `src/i18n/locales/en.json`.

**Tech Stack:**
- Expo SDK 58 (`expo ~58.0.22`), React Native 0.88, React 19.3, TypeScript 6 (strict), Expo Router 58
- Data and state: TanStack Query 5 with the async-storage persister, Zustand 5
- Forms: react-hook-form 7, zod 4, @hookform/resolvers 7
- i18n: i18next 26 and react-i18next 17
- Styling: NativeWind 4.2 with Tailwind CSS 3.4
- Device APIs: expo-secure-store, expo-localization, expo-notifications, expo-network
- Testing and linting: Jest 30 with jest-expo 58, @testing-library/react-native 14, ESLint 9 with eslint-config-expo and eslint-plugin-i18next

**Spec:** `docs/superpowers/specs/2026-10-31-subs-mvp-design.md`. §8 covers the app, §5 the API, and §10 testing.

## Global Constraints

- **Expo SDK 58.** Add Expo and native packages only with `npx expo install <pkg>`. Pure-JS packages (zustand, i18next, react-hook-form, zod, TanStack) use `npm install`. Never hand-pin React Native package versions.
- **Expo has changed since most training data.** Before touching an Expo API that isn't shown verbatim in this plan, read `https://docs.expo.dev/versions/v58.0.0/` or `https://docs.expo.dev/llms.txt`.
- **Routes live in `app/src/app/`.** Every file there becomes a route, so no test files or helpers go there. Screens live in `app/src/screens/`, and each route file is `export { default } from '@/screens/...';`.
- **Strings.** No user-facing literal strings in JSX. All text goes through `t()` keys in `src/i18n/locales/en.json`. ESLint `i18next/no-literal-string` (mode `jsx-only`) enforces this. Plurals use i18next `_one` / `_other` (and `_zero` where the copy differs).
- **Adding a language** means adding `src/i18n/locales/<xx>.json`, adding `<xx>` to `SUPPORTED_LOCALES`, and adding one `resources` line in `src/i18n/index.ts` (tsc enforces the last one). The backend side is `backend/lang/<xx>/` plus `config/subs.php` `locales`.
- **Money is integer minor units** in every API payload. Decimals per currency come from `Intl.NumberFormat(...).resolvedOptions().maximumFractionDigits`, which is the same CLDR data the backend uses. Floats never go to the API.
- **Billing dates are `YYYY-MM-DD` strings** end to end. Format them with `Intl` and `timeZone: 'UTC'`, and never through a local `Date`.
- **API configuration.** The base URL comes from `process.env.EXPO_PUBLIC_API_URL`, for example `http://localhost:8080/api/v1`. The token goes in an `Authorization: Bearer` header. It is stored in `expo-secure-store` on mobile and `localStorage` on web.
- **Response shapes.** Resources come wrapped as `{ data: ... }`, except:
  - `POST /auth/register` and `POST /auth/login` return `{ token, user }` unwrapped.
  - `GET /dashboard` returns a plain object.
  - `GET /notifications/unread-count` returns `{ count }`.
  - `GET|PUT .../reminders` returns `{ data, meta: { uses_defaults } }`.
  - Paginated lists return `{ data, links, meta: { current_page, last_page, total } }`.
- **Errors.** Laravel errors are `{ message, errors? }`. A 422 has `errors: Record<field, string[]>`. All server messages arrive already translated.
- **Server limits.** At most 5 reminder rules. `days_before` is 0–60, `time_of_day` is `HH:MM`, and `channels` ⊆ `push`, `in_app`, `email`. `amount` is 0–100000000, `interval_count` is 1–365, and the password is at least 8 characters.
- **Tests.** React Native Testing Library 14 is fully async: always `await render(...)`, `await fireEvent...`, `await renderHook(...)`, `await act(...)`. `expo-router` is mocked globally in `jest.setup.ts`, so screens are tested as plain components that assert on `router.push`, `router.replace` and `router.back` calls.
- **Styling.** NativeWind `className` on React Native components. Dark mode uses `dark:` variants and follows the system scheme.
- **Run from the `app` folder.** Every command below runs in `cd ~/Sites/subs/app` unless it says otherwise. The backend runs in Docker at `http://localhost:8080`.
- **Checks before commit.** Every task finishes with `npm run typecheck && npm run lint && npm test` green.

## Rulings that deviate from the spec (flagged for review)

1. **`<SpendChart>` uses plain `View` bars, not victory or victory-native.** victory-native needs Skia, plus a wasm build on web, just to draw one bar breakdown. The component boundary stays, so a chart library can replace the internals later.
2. **The first-payment date is a validated `YYYY-MM-DD` text field.** There is no cross-platform date picker dependency, and `@react-native-community/datetimepicker` has no web support.
3. **`subscriptions/new` is one scrolling form** with three numbered sections (service, payment, optional reminders) instead of three separate steps.
4. **Mobile push needs an EAS `projectId`** to get an Expo push token, and EAS is deferred to launch. Until `npx eas-cli@latest init` runs, mobile push reports "unsupported" and the app keeps working with in-app and email reminders. Web push works with the VAPID public key.

## Review Focus

1. **Amount input:** typing `12,99`, `1.299,50`, `1,299`, `1600` (JPY) or `5.000` (KWD) gives the correct minor units. `1.5` for JPY shows a field error. `12.345` for EUR is read as 12,345.00, and the form's "Saved as €12,345.00" preview makes that reading visible before saving. *(Task 2 `money.test.ts`, Task 10 `schema.test.ts` and `NewSubscriptionScreen.test.tsx`)*
2. **Expired or revoked token:** a 401 on any authenticated request clears the token and the cached data and returns the user to login exactly once. A wrong password at login is a 422 and must not trigger that. *(Task 3 `client.test.ts`, `session.test.ts`)*
3. **Server validation:** a 422 field error (for example "email already taken") appears under the matching field, an unmapped one appears as a form message, and a 429 says "too many attempts" rather than "something went wrong". *(Task 5 `forms.test.ts`, `errors.test.ts`; Task 6 `LoginScreen.test.tsx`)*
4. **Offline:** a failed `fetch` becomes a NetworkError with an "offline" message, mutations fail immediately instead of hanging, and cached query data is still shown. *(Task 3 `client.test.ts`, Task 4 `hooks.test.tsx`)*
5. **Push not available:** permission denied, no projectId, or a browser without PushManager returns a status the UI explains, never throws, and never blocks saving a subscription. *(Task 9 `push.test.ts`, `PushIntroScreen.test.tsx`)*

`app/src/i18n/keys.test.ts`:

```ts
import fs from 'node:fs';
import path from 'node:path';

import en from './locales/en.json';

type Tree = { [key: string]: string | Tree };

function sourceFiles(dir: string): string[] {
  return fs.readdirSync(dir, { withFileTypes: true }).flatMap((entry) => {
    const full = path.join(dir, entry.name);
    if (entry.isDirectory()) return sourceFiles(full);
    return /\.tsx?$/.test(entry.name) && !/\.test\.tsx?$/.test(entry.name) ? [full] : [];
  });
}

function hasKey(tree: Tree, key: string): boolean {
  const parts = key.split('.');
  const last = parts.pop() as string;
  let node: string | Tree | undefined = tree;
  for (const part of parts) node = typeof node === 'object' ? node[part] : undefined;
  if (typeof node !== 'object') return false;
  return [last, `${last}_one`, `${last}_other`].some((k) => typeof node[k] === 'string');
}

test('every translation key used in src exists in en.json', () => {
  const used = new Set<string>();
  for (const file of sourceFiles(path.join(__dirname, '..'))) {
    const code = fs.readFileSync(file, 'utf8');
    for (const m of code.matchAll(/\bt\(\s*['"]([\w.]+)['"]/g)) used.add(m[1]);
    // zod and rule messages are keys rendered later through translateError()
    for (const m of code.matchAll(/['"](validation\.[\w.]+)['"]/g)) used.add(m[1]);
  }

  if (used.size === 0) return; // Task 5 makes this strict once code uses keys
  expect([...used].filter((key) => !hasKey(en as Tree, key))).toEqual([]);
});
```

```ts
const decimalsCache = new Map<string, number>();

/** Minor-unit digits of a currency per CLDR, the same digits the backend uses. */
export function currencyDecimals(currency: string): number {
  let decimals = decimalsCache.get(currency);
  if (decimals === undefined) {
    decimals = new Intl.NumberFormat('en', { style: 'currency', currency }).resolvedOptions().maximumFractionDigits ?? 2;
    decimalsCache.set(currency, decimals);
  }
  return decimals;
}

export function formatMoney(minor: number, currency: string, locale: string): string {
  const decimals = currencyDecimals(currency);
  return new Intl.NumberFormat(locale, {
    style: 'currency',
    currency,
    minimumFractionDigits: decimals,
    maximumFractionDigits: decimals,
  }).format(minor / 10 ** decimals);
}

/**
 * Parses what people type ("12.99", "12,99", "1.299,50", "1,600") into minor units.
 * The last separator is the decimal mark when 1..decimals digits follow it; a
 * separator followed by exactly three digits is a thousands separator when the
 * currency has fewer than three decimals. Returns null for anything else.
 */
export function parseMoney(input: string, currency: string): number | null {
  const decimals = currencyDecimals(currency);
  const s = input.trim().replace(/[\s ']/g, '');
  if (!/^\d[\d.,]*$/.test(s)) return null;

  const last = Math.max(s.lastIndexOf('.'), s.lastIndexOf(','));
  let whole = s;
  let fraction = '';

  if (last !== -1) {
    const tail = s.slice(last + 1);
    const isDecimal = tail.length >= 1 && tail.length <= decimals && !(tail.length === 3 && decimals < 3);
    if (isDecimal) {
      whole = s.slice(0, last);
      fraction = tail;
    } else if (tail.length !== 3) {
      return null;
    }
  }

  if (!/^\d+$/.test(whole) && !/^\d{1,3}([.,]\d{3})+$/.test(whole)) return null;

  const minor = Number(whole.replace(/[.,]/g, '')) * 10 ** decimals + Number(fraction.padEnd(decimals, '0') || '0');
  return Number.isSafeInteger(minor) ? minor : null;
}

/** Minor units as an editable decimal string ("12.99"). */
export function minorToInput(minor: number, currency: string): string {
  const decimals = currencyDecimals(currency);
  return (minor / 10 ** decimals).toFixed(decimals);
}
```

```ts
import { getCalendars } from 'expo-localization';

function parts(isoDate: string): [number, number, number] {
  const [y, m, d] = isoDate.slice(0, 10).split('-').map(Number);
  return [y, m, d];
}

/** A billing date (YYYY-MM-DD), formatted without shifting it through the local timezone. */
export function formatDate(isoDate: string, locale: string): string {
  const [y, m, d] = parts(isoDate);
  return new Intl.DateTimeFormat(locale, { dateStyle: 'medium', timeZone: 'UTC' }).format(new Date(Date.UTC(y, m - 1, d)));
}

/** A timestamp (ISO 8601 with offset) in the device's timezone. */
export function formatDateTime(iso: string, locale: string): string {
  return new Intl.DateTimeFormat(locale, { dateStyle: 'medium', timeStyle: 'short' }).format(new Date(iso));
}

/** Today's date (YYYY-MM-DD) in the given IANA timezone (the device's when omitted). */
export function todayIso(timeZone?: string): string {
  const fields = new Intl.DateTimeFormat('en-US', { timeZone, year: 'numeric', month: '2-digit', day: '2-digit' })
    .formatToParts(new Date());
  const get = (type: string) => fields.find((p) => p.type === type)?.value ?? '';
  return `${get('year')}-${get('month')}-${get('day')}`;
}

export function isValidIsoDate(value: string): boolean {
  if (!/^\d{4}-\d{2}-\d{2}$/.test(value)) return false;
  const [y, m, d] = parts(value);
  const date = new Date(Date.UTC(y, m - 1, d));
  return date.getUTCFullYear() === y && date.getUTCMonth() === m - 1 && date.getUTCDate() === d;
}

export function deviceTimeZone(): string {
  return getCalendars()[0]?.timeZone ?? Intl.DateTimeFormat().resolvedOptions().timeZone ?? 'UTC';
}
```

`app/src/api/client.ts`:

```ts
import { API_URL } from './config';
import { ApiError, NetworkError } from './errors';

type Method = 'GET' | 'POST' | 'PATCH' | 'PUT' | 'DELETE';
type Query = Record<string, string | number | null | undefined>;

type Hooks = {
  getToken: () => string | null;
  onUnauthorized: () => void;
  getLocale: () => string;
};

let hooks: Hooks = { getToken: () => null, onUnauthorized: () => {}, getLocale: () => 'en' };

/** Wired once by the session module, which owns the token. */
export function configureApi(next: Hooks): void {
  hooks = next;
}

function queryString(query?: Query): string {
  const pairs = Object.entries(query ?? {})
    .filter(([, value]) => value !== undefined && value !== null && value !== '')
    .map(([key, value]) => `${encodeURIComponent(key)}=${encodeURIComponent(String(value))}`);
  return pairs.length ? `?${pairs.join('&')}` : '';
}

export async function api<T>(path: string, options: { method?: Method; body?: unknown; query?: Query } = {}): Promise<T> {
  const { method = 'GET', body, query } = options;
  const token = hooks.getToken();

  let response: Response;
  try {
    response = await fetch(`${API_URL}${path}${queryString(query)}`, {
      method,
      headers: {
        Accept: 'application/json',
        'Accept-Language': hooks.getLocale(),
        ...(body !== undefined ? { 'Content-Type': 'application/json' } : {}),
        ...(token ? { Authorization: `Bearer ${token}` } : {}),
      },
      body: body !== undefined ? JSON.stringify(body) : undefined,
    });
  } catch (error) {
    throw new NetworkError(error);
  }

  if (response.status === 204) return undefined as T;

  const data = (await response.json().catch(() => null)) as { message?: string; errors?: Record<string, string[]> } | null;

  if (!response.ok) {
    // Only a request that carried a token can mean "your session ended".
    if (response.status === 401 && token) hooks.onUnauthorized();
    throw new ApiError(response.status, data?.message ?? response.statusText, data?.errors ?? {});
  }

  return data as T;
}
```

```ts
  },
```

```ts
  onUnauthorized: () => void useSession.getState().signOut(),
```

```tsx
import { QueryClient, QueryClientProvider } from '@tanstack/react-query';
import { render, renderHook } from '@testing-library/react-native';
import type { ReactElement, ReactNode } from 'react';

import { API_URL } from '@/api/config';

export type MockResponse = { status?: number; body?: unknown };
export type MockRoute = MockResponse | ((request: { path: string; body: unknown }) => MockResponse);
export type RecordedCall = { method: string; path: string; body: unknown };

/**
 * Replaces fetch. Routes are keyed "METHOD /path" (exact, with query) or "METHOD /path"
 * without the query string; an unmocked request rejects, which the client reports as a NetworkError.
 */
export function mockApi(routes: Record<string, MockRoute>): RecordedCall[] {
  const calls: RecordedCall[] = [];
  global.fetch = jest.fn(async (input: RequestInfo | URL, init: RequestInit = {}) => {
    const method = init.method ?? 'GET';
    const path = String(input).replace(API_URL, '');
    const body = typeof init.body === 'string' ? JSON.parse(init.body) : undefined;
    calls.push({ method, path, body });
    const route = routes[`${method} ${path}`] ?? routes[`${method} ${path.split('?')[0]}`];
    if (route === undefined) throw new Error(`Unmocked request: ${method} ${path}`);
    const { status = 200, body: responseBody = null } = typeof route === 'function' ? route({ path, body }) : route;
    return { ok: status >= 200 && status < 300, status, statusText: String(status), json: async () => responseBody } as Response;
  }) as typeof fetch;
  return calls;
}

export function createTestQueryClient(): QueryClient {
  return new QueryClient({
    defaultOptions: {
      queries: { retry: false, gcTime: Infinity },
      mutations: { retry: false, networkMode: 'always' },
    },
  });
}

function wrapperFor(client: QueryClient) {
  return function Wrapper({ children }: { children: ReactNode }) {
    return <QueryClientProvider client={client}>{children}</QueryClientProvider>;
  };
}

export async function renderWithProviders(ui: ReactElement, client: QueryClient = createTestQueryClient()) {
  const result = await render(ui, { wrapper: wrapperFor(client) });
  return { ...result, client };
}

export function renderHookWithProviders<T>(hook: () => T, client: QueryClient = createTestQueryClient()) {
  return renderHook(hook, { wrapper: wrapperFor(client) });
```

```ts
import { ApiError, NetworkError } from '@/api/errors';
import i18n from '@/i18n';

/** One line to show for a failed request. */
export function errorMessage(error: unknown): string {
  if (error instanceof NetworkError) return i18n.t('errors.network');
  if (error instanceof ApiError) {
    if (error.status === 429) return i18n.t('errors.tooMany');
    if (error.status === 404) return i18n.t('errors.notFound');
    if (error.status < 500 && error.message) return error.message;
  }
  return i18n.t('errors.generic');
}

/** Field messages are either our keys (client validation) or server text (already translated). */
export function translateError(message?: string): string | undefined {
  if (!message) return undefined;
  return i18n.exists(message) ? i18n.t(message) : message;
}
```

```ts
import type { FieldValues, Path, UseFormSetError } from 'react-hook-form';

import { ApiError } from '@/api/errors';

/**
 * Shows a 422's field errors under the form's fields. `fields` are form fields that share
 * the API's name; `fieldMap` maps other API names (snake_case) to form fields.
 * Returns false when nothing was mapped, so the caller shows a form-level message instead.
 */
export function applyServerErrors<T extends FieldValues>(
  error: unknown,
  setError: UseFormSetError<T>,
  fields: readonly Path<T>[],
  fieldMap: Partial<Record<string, Path<T>>> = {},
): boolean {
  if (!(error instanceof ApiError) || error.status !== 422) return false;

  let mapped = false;
  for (const [key, messages] of Object.entries(error.errors)) {
    const field = fieldMap[key] ?? (fields.includes(key as Path<T>) ? (key as Path<T>) : undefined);
    if (field && messages[0]) {
      setError(field, { type: 'server', message: messages[0] });
      mapped = true;
    }
  }
  return mapped;
}
```

```ts
import { useEffect, useState } from 'react';

export function useDebounced<T>(value: T, ms: number): T {
  const [debounced, setDebounced] = useState(value);
  useEffect(() => {
    const timer = setTimeout(() => setDebounced(value), ms);
    return () => clearTimeout(timer);
  }, [value, ms]);
  return debounced;
}
```

```tsx
import { useTranslation } from 'react-i18next';

import { AppText } from './AppText';
import { Button } from './Button';
import { TextField } from './TextField';

type Props<T extends string | number | null> = {
  label: string;
  value: T;
  options: readonly { value: T; label: string }[];
  onChange: (value: T) => void;
  searchable?: boolean;
  error?: string;
};

export function SelectField<T extends string | number | null>({ label, value, options, onChange, searchable, error }: Props<T>) {
  const { t } = useTranslation();
  const [open, setOpen] = useState(false);
  const [query, setQuery] = useState('');
  const selected = options.find((o) => o.value === value);
  const showSearch = searchable ?? options.length > 10;
  const visible = query ? options.filter((o) => o.label.toLowerCase().includes(query.toLowerCase())) : options;

  const close = () => {
    setOpen(false);
    setQuery('');
  };

  return (
    <View className="gap-1">
      <AppText variant="muted">{label}</AppText>
      <Pressable
        accessibilityRole="button"
        accessibilityLabel={label}
        onPress={() => setOpen(true)}
        className="min-h-12 justify-center rounded-xl border border-neutral-300 bg-white px-3 dark:border-neutral-700 dark:bg-neutral-900">
        <AppText>{selected?.label ?? ''}</AppText>
      </Pressable>
      {error ? <AppText variant="error">{error}</AppText> : null}
      <Modal visible={open} animationType="slide" onRequestClose={close}>
        <View className="flex-1 gap-3 bg-white p-4 pt-12 dark:bg-neutral-950">
          <AppText variant="heading">{label}</AppText>
          {showSearch ? <TextField label={t('common.search')} value={query} onChangeText={setQuery} autoFocus /> : null}
          <FlatList
            data={visible}
            keyExtractor={(o) => String(o.value)}
            keyboardShouldPersistTaps="handled"
            renderItem={({ item }) => (
              <Pressable
                accessibilityRole="button"
                accessibilityLabel={item.label}
                onPress={() => {
                  onChange(item.value);
                  close();
                }}
                className="border-b border-neutral-200 py-3 dark:border-neutral-800">
                <AppText className={item.value === value ? 'font-semibold' : undefined}>{item.label}</AppText>
              </Pressable>
            )}
          />
          <Button label={t('common.cancel')} variant="secondary" onPress={close} />
        </View>
      </Modal>
    </View>
  );
}
```

```tsx
import { zodResolver } from '@hookform/resolvers/zod';
import { useQueryClient } from '@tanstack/react-query';
import { router } from 'expo-router';
import { useState } from 'react';
import { useForm } from 'react-hook-form';
import { useTranslation } from 'react-i18next';
import { z } from 'zod';

import { authApi } from '@/api/auth';
import { keys } from '@/api/keys';
import { useSession } from '@/auth/session';
import { Button } from '@/components/Button';
import { ErrorMessage } from '@/components/ErrorMessage';
import { FormTextField } from '@/components/FormTextField';
import { Screen } from '@/components/Screen';
import { TextLink } from '@/components/TextLink';
import { deviceName } from '@/lib/device';
import { applyServerErrors } from '@/lib/forms';

const schema = z.object({
  email: z.email('validation.email'),
  password: z.string().min(1, 'validation.required'),
});

type Values = z.infer<typeof schema>;

export default function LoginScreen() {
  const { t } = useTranslation();
  const qc = useQueryClient();
  const [formError, setFormError] = useState<unknown>(null);
  const { control, handleSubmit, setError, formState } = useForm<Values>({
    resolver: zodResolver(schema),
    defaultValues: { email: '', password: '' },
  });

  const onSubmit = handleSubmit(async (values) => {
    setFormError(null);
    try {
      const { token, user } = await authApi.login({ ...values, device_name: deviceName() });
      qc.setQueryData(keys.me, user);
      await useSession.getState().signIn(token);
    } catch (error) {
      if (!applyServerErrors(error, setError, ['email', 'password'])) setFormError(error);
    }
  });

  return (
    <Screen>
      <FormTextField control={control} name="email" label={t('auth.email')} autoCapitalize="none" autoComplete="email" keyboardType="email-address" />
      <FormTextField control={control} name="password" label={t('auth.password')} secureTextEntry autoComplete="current-password" />
      <ErrorMessage error={formError} />
      <Button label={t('auth.login')} onPress={onSubmit} loading={formState.isSubmitting} />
      <TextLink label={t('auth.forgot')} onPress={() => router.push('/forgot-password')} />
      <TextLink label={t('auth.noAccount')} onPress={() => router.push('/register')} />
    </Screen>
  );
}
```

```tsx
import { zodResolver } from '@hookform/resolvers/zod';
import { router, useLocalSearchParams } from 'expo-router';
import { useState } from 'react';
import { useForm } from 'react-hook-form';
import { useTranslation } from 'react-i18next';
import { z } from 'zod';

import { authApi } from '@/api/auth';
import { AppText } from '@/components/AppText';
import { Banner } from '@/components/Banner';
import { Button } from '@/components/Button';
import { ErrorMessage } from '@/components/ErrorMessage';
import { FormTextField } from '@/components/FormTextField';
import { Screen } from '@/components/Screen';
import { applyServerErrors } from '@/lib/forms';

const schema = z.object({ password: z.string().min(8, 'validation.passwordMin') });

export default function ResetPasswordScreen() {
  const { t } = useTranslation();
  const { token, email } = useLocalSearchParams<{ token?: string; email?: string }>();
  const [done, setDone] = useState<string | null>(null);
  const [formError, setFormError] = useState<unknown>(null);
  const { control, handleSubmit, setError, formState } = useForm({ resolver: zodResolver(schema), defaultValues: { password: '' } });

  const backToLogin = <Button label={t('auth.backToLogin')} variant="secondary" onPress={() => router.replace('/login')} />;

  if (!token || !email) {
    return (
      <Screen>
        <AppText>{t('auth.invalidLink')}</AppText>
        {backToLogin}
      </Screen>
    );
  }

  const onSubmit = handleSubmit(async ({ password }) => {
    setFormError(null);
    try {
      setDone((await authApi.resetPassword({ token, email, password })).message);
    } catch (error) {
      // An expired token comes back as an "email" error: show it as the form message.
      if (!applyServerErrors(error, setError, ['password'])) setFormError(error);
    }
  });

  return (
    <Screen>
      {done ? (
        <Banner message={done} />
      ) : (
        <>
          <FormTextField control={control} name="password" label={t('auth.newPassword')} secureTextEntry autoComplete="new-password" />
          <ErrorMessage error={formError} />
          <Button label={t('auth.resetPassword')} onPress={onSubmit} loading={formState.isSubmitting} />
        </>
      )}
      {backToLogin}
    </Screen>
  );
}
```

```ts
    shouldSetBadge: false,

export function isPushSupported(): boolean {
  return Platform.OS === 'ios' || Platform.OS === 'android';

/** Asks permission if needed and registers this device's Expo token with the API. Never throws. */
export async function enablePush(): Promise<PushResult> {
  const id = projectId();
  if (!isPushSupported() || !id) return 'unsupported';

  try {
    if (Platform.OS === 'android') {
      await Notifications.setNotificationChannelAsync('default', {
        name: 'default',
        importance: Notifications.AndroidImportance.DEFAULT,
      });
    }

    let { status } = await Notifications.getPermissionsAsync();
    if (status !== 'granted') ({ status } = await Notifications.requestPermissionsAsync());
    if (status !== 'granted') {
      await prefs.set('push.enabled', '0');
      return 'denied';
    }

    const { data: token } = await Notifications.getExpoPushTokenAsync({ projectId: id });
    await devicesApi.register(token, Platform.OS === 'ios' ? 'ios' : 'android');
    await prefs.set('push.token', token);
    await prefs.set('push.enabled', '1');
    return 'enabled';
  } catch {
    await prefs.set('push.enabled', '0');
    return 'failed';
  }
}

export async function disablePush(): Promise<void> {
  const token = await prefs.get('push.token');
  if (token) await devicesApi.unregister(token).catch(() => undefined);
  await prefs.remove('push.token');
  await prefs.set('push.enabled', '0');
}

  return (await prefs.get('push.enabled')) === '1';
```

```ts
import { devicesApi } from '@/api/devices';
import { prefs } from '@/lib/prefs';

import type { PushResult } from './types';

export type { PushResult } from './types';

const VAPID_PUBLIC_KEY = process.env.EXPO_PUBLIC_VAPID_PUBLIC_KEY ?? '';

function urlBase64ToUint8Array(base64: string): Uint8Array<ArrayBuffer> {
  const padded = (base64 + '='.repeat((4 - (base64.length % 4)) % 4)).replace(/-/g, '+').replace(/_/g, '/');
  const raw = atob(padded);
  const bytes = new Uint8Array(new ArrayBuffer(raw.length));
  for (let i = 0; i < raw.length; i++) bytes[i] = raw.charCodeAt(i);
  return bytes;
}

export function isPushSupported(): boolean {
  return (
    VAPID_PUBLIC_KEY !== '' &&
    typeof window !== 'undefined' &&
    'serviceWorker' in navigator &&
    'PushManager' in window &&
    'Notification' in window
  );
}

/** Subscribes this browser through the service worker and sends the subscription to the API. Never throws. */
export async function enablePush(): Promise<PushResult> {
  if (!isPushSupported()) return 'unsupported';

  try {
    const permission = await Notification.requestPermission();
    if (permission !== 'granted') {
      await prefs.set('push.enabled', '0');
      return 'denied';
    }

    const registration = await navigator.serviceWorker.register('/sw.js');
    await navigator.serviceWorker.ready;
    const subscription =
      (await registration.pushManager.getSubscription()) ??
      (await registration.pushManager.subscribe({ userVisibleOnly: true, applicationServerKey: urlBase64ToUint8Array(VAPID_PUBLIC_KEY) }));

    const json = subscription.toJSON();
    await devicesApi.webPushSubscribe({
      endpoint: subscription.endpoint,
      keys: { p256dh: json.keys?.p256dh ?? '', auth: json.keys?.auth ?? '' },
      content_encoding: 'aes128gcm',
    });
    await prefs.set('push.enabled', '1');
    return 'enabled';
  } catch {
    await prefs.set('push.enabled', '0');
    return 'failed';
  }
}

export async function disablePush(): Promise<void> {
  try {
    const registration = await navigator.serviceWorker?.getRegistration('/sw.js');
    const subscription = await registration?.pushManager.getSubscription();
    if (subscription) {
      await devicesApi.webPushUnsubscribe(subscription.endpoint).catch(() => undefined);
      await subscription.unsubscribe();
    }
  } finally {
    await prefs.set('push.enabled', '0');
  }
}

export async function isPushEnabled(): Promise<boolean> {
  return (await prefs.get('push.enabled')) === '1';
}
```

```ts
import { z } from 'zod';

import type { SubscriptionPayload } from '@/api/subscriptions';
import type { Subscription } from '@/api/types';
import { isValidIsoDate } from '@/lib/dates';
import { minorToInput, parseMoney } from '@/lib/money';

const MAX_AMOUNT = 100_000_000;

/** Form state keeps what people type (strings); toPayload converts to the API's types. */
export const subscriptionFormSchema = z
  .object({
    serviceId: z.number().int().nullable(),
    serviceName: z.string().max(100),
    categoryId: z.number().int().nullable(),
    amount: z.string(),
    currency: z.string().regex(/^[A-Z]{3}$/, 'validation.currency'),
    period: z.enum(['week', 'month', 'year']),
    intervalCount: z.string(),
    firstPaymentDate: z.string().refine(isValidIsoDate, 'validation.date'),
    notes: z.string().max(1000),
  })
  .superRefine((v, ctx) => {
    if (v.serviceId === null && v.serviceName.trim() === '') {
      ctx.addIssue({ code: 'custom', path: ['serviceName'], message: 'validation.serviceRequired' });
    }
    const minor = parseMoney(v.amount, v.currency);
    if (minor === null) {
      ctx.addIssue({ code: 'custom', path: ['amount'], message: 'validation.amount' });
    } else if (minor > MAX_AMOUNT) {
      ctx.addIssue({ code: 'custom', path: ['amount'], message: 'validation.amountTooLarge' });
    }
    const interval = Number(v.intervalCount);
    if (!/^\d+$/.test(v.intervalCount) || interval < 1 || interval > 365) {
      ctx.addIssue({ code: 'custom', path: ['intervalCount'], message: 'validation.interval' });
    }
  });

export type SubscriptionFormValues = z.infer<typeof subscriptionFormSchema>;

export function defaultFormValues(currency: string, today: string): SubscriptionFormValues {
  return {
    serviceId: null,
    serviceName: '',
    categoryId: null,
    amount: '',
    currency,
    period: 'month',
    intervalCount: '1',
    firstPaymentDate: today,
    notes: '',
  };
}

export function toFormValues(s: Subscription): SubscriptionFormValues {
  return {
    serviceId: s.service.id,
    serviceName: s.service.name,
    categoryId: s.category.id,
    amount: minorToInput(s.amount, s.currency),
    currency: s.currency,
    period: s.period,
    intervalCount: String(s.interval_count),
    firstPaymentDate: s.first_payment_date,
    notes: s.notes ?? '',
  };
}

/** Call only with values that passed subscriptionFormSchema. */
export function toPayload(v: SubscriptionFormValues): SubscriptionPayload {
  const notes = v.notes.trim();
  return {
    ...(v.serviceId !== null ? { service_id: v.serviceId } : { service_name: v.serviceName.trim() }),
    ...(v.categoryId !== null ? { category_id: v.categoryId } : {}),
    amount: parseMoney(v.amount, v.currency) as number,
    currency: v.currency,
    period: v.period,
    interval_count: Number(v.intervalCount),
    first_payment_date: v.firstPaymentDate,
    notes: notes === '' ? null : notes,
  };
}
```

```ts
import type { Channel, ReminderRule, ReminderRuleInput } from '@/api/types';

export const CHANNELS = ['push', 'in_app', 'email'] as const satisfies readonly Channel[];
export const MAX_RULES = 5;

export type RuleErrors = { daysBefore?: string; timeOfDay?: string; channels?: string };

/** Mirrors the API's rules (0–60 days, HH:MM, ≥1 channel, one rule per lead time); messages are i18n keys. */
export function validateRules(rules: ReminderRuleInput[]): RuleErrors[] {
  return rules.map((rule) => {
    const errors: RuleErrors = {};
    if (!Number.isInteger(rule.days_before) || rule.days_before < 0 || rule.days_before > 60) {
      errors.daysBefore = 'validation.daysBefore';
    } else if (rules.filter((other) => other.days_before === rule.days_before).length > 1) {
      errors.daysBefore = 'validation.duplicateDays';
    }
    if (!/^([01]\d|2[0-3]):[0-5]\d$/.test(rule.time_of_day)) errors.timeOfDay = 'validation.time';
    if (rule.channels.length === 0) errors.channels = 'validation.channels';
    return errors;
  });
}

export function hasRuleErrors(errors: RuleErrors[]): boolean {
  return errors.some((e) => Object.keys(e).length > 0);
}

export function defaultRule(existing: ReminderRuleInput[]): ReminderRuleInput {
  const used = new Set(existing.map((r) => r.days_before));
  const days = [1, 3, 7, 0, 14, 30].find((d) => !used.has(d)) ?? 2;
  return { days_before: days, time_of_day: '09:00', channels: ['push', 'in_app'] };
}

export function toRuleInputs(rules: ReminderRule[]): ReminderRuleInput[] {
  return rules.map(({ days_before, time_of_day, channels }) => ({ days_before, time_of_day, channels }));
}
```

```tsx
import { useState } from 'react';
import { useTranslation } from 'react-i18next';

import { useReminderDefaults, useSubscriptionRules, useUpdateSubscriptionRules } from '@/api/reminders';
import type { ReminderRuleInput } from '@/api/types';
import { AppText } from '@/components/AppText';
import { Button } from '@/components/Button';
import { ErrorMessage } from '@/components/ErrorMessage';
import { Loading } from '@/components/Loading';
import { ReminderRulesEditor, RuleSummary } from '@/components/ReminderRulesEditor';
import { Section } from '@/components/Section';
import { hasRuleErrors, toRuleInputs, validateRules, type RuleErrors } from '@/features/reminders/rules';

/** A subscription's own rules replace the user's defaults; an empty list reverts to them. */
export function SubscriptionReminders({ subscriptionId }: { subscriptionId: number }) {
  const { t } = useTranslation();
  const rules = useSubscriptionRules(subscriptionId);
  const defaults = useReminderDefaults();
  const save = useUpdateSubscriptionRules(subscriptionId);
  const [draft, setDraft] = useState<ReminderRuleInput[] | null>(null);
  const [errors, setErrors] = useState<RuleErrors[]>([]);

  if (!rules.data) return <Loading />;
  const current = rules.data;

  const submit = (next: ReminderRuleInput[]) => {
    const found = validateRules(next);
    setErrors(found);
    if (hasRuleErrors(found)) return;
    save.mutate(next, { onSuccess: () => setDraft(null) });
  };

  return (
    <Section title={t('subscription.reminders')}>
      {draft === null ? (
        <>
          {current.usesDefaults ? <AppText variant="muted">{t('subscription.usingDefaults')}</AppText> : <RuleSummary rules={current.rules} />}
          {save.isSuccess ? <AppText variant="muted">{t('reminders.saved')}</AppText> : null}
          <Button
            label={t('subscription.customize')}
            variant="secondary"
            onPress={() => setDraft(toRuleInputs(current.usesDefaults ? (defaults.data ?? []) : current.rules))}
          />
          {current.usesDefaults ? null : (
            <Button label={t('subscription.useDefaults')} variant="secondary" loading={save.isPending} onPress={() => submit([])} />
          )}
        </>
      ) : (
        <>
          <ReminderRulesEditor rules={draft} onChange={setDraft} errors={errors} />
          <Button label={t('common.save')} loading={save.isPending} onPress={() => submit(draft)} />
          <Button label={t('common.cancel')} variant="secondary" onPress={() => setDraft(null)} />
        </>
      )}
      <ErrorMessage error={save.error} />
    </Section>
  );
}
```

```tsx
export default function InboxScreen() {

      void qc.invalidateQueries({ queryKey: keys.notifications });
    }, [qc]),
```

```tsx
import { useSession } from '@/auth/session';
import { AppText } from '@/components/AppText';
import { Banner } from '@/components/Banner';
import { Button } from '@/components/Button';
import { ErrorMessage } from '@/components/ErrorMessage';
import { Loading } from '@/components/Loading';
import { ReminderRulesEditor, RuleSummary } from '@/components/ReminderRulesEditor';

import { TextField } from '@/components/TextField';

import { VerifyEmailBanner } from '@/components/VerifyEmailBanner';

import { SUPPORTED_LOCALES } from '@/i18n';
import { currencyOptions } from '@/lib/currencies';
import { deviceTimeZone } from '@/lib/dates';
import { disablePush, enablePush, isPushEnabled, isPushSupported, type PushResult } from '@/push';

function ProfileSection({ user }: { user: User }) {
  const { t } = useTranslation();
  const update = useUpdateMe();
  const [name, setName] = useState(user.name);
  const deviceZone = deviceTimeZone();

  return (
    <Section title={t('settings.profile')}>
      <TextField label={t('settings.name')} value={name} onChangeText={setName} autoComplete="name" />
      <Button label={t('common.save')} variant="secondary" disabled={name.trim() === '' || name === user.name} onPress={() => update.mutate({ name: name.trim() })} />
      <SelectField label={t('settings.currency')} value={user.currency} options={currencyOptions(user.currency)} onChange={(currency) => update.mutate({ currency })} />
      <SelectField
        label={t('settings.language')}
        value={user.locale}
        options={SUPPORTED_LOCALES.map((locale) => ({ value: locale, label: t(`languages.${locale}`) }))}
        onChange={(locale) => update.mutate({ locale })}
      />
      <AppText variant="muted">{t('settings.timezone', { timezone: user.timezone })}</AppText>
      {deviceZone !== user.timezone ? (
        <Button label={t('settings.useDeviceTimezone', { timezone: deviceZone })} variant="secondary" onPress={() => update.mutate({ timezone: deviceZone })} />
      ) : null}
      {user.email_verified ? <AppText variant="muted">{t('settings.emailVerified')}</AppText> : <VerifyEmailBanner />}
      {update.isSuccess ? <AppText variant="muted">{t('settings.saved')}</AppText> : null}
      <ErrorMessage error={update.error} />
    </Section>
  );
}

function DefaultRemindersSection() {
  const { t } = useTranslation();
  const defaults = useReminderDefaults();
  const save = useUpdateReminderDefaults();
  const [draft, setDraft] = useState<ReminderRuleInput[] | null>(null);
  const [errors, setErrors] = useState<RuleErrors[]>([]);

  if (!defaults.data) return <Loading />;

  const submit = (rules: ReminderRuleInput[]) => {
    const found = validateRules(rules);
    setErrors(found);
    if (!hasRuleErrors(found)) save.mutate(rules, { onSuccess: () => setDraft(null) });
  };

  return (
    <Section title={t('settings.defaultReminders')}>
      {draft === null ? (
        <>
          <RuleSummary rules={defaults.data} />
          <Button label={t('common.edit')} variant="secondary" onPress={() => setDraft(toRuleInputs(defaults.data))} />
        </>
      ) : (
        <>
          <ReminderRulesEditor rules={draft} onChange={setDraft} errors={errors} />
          <Button label={t('settings.saveReminders')} loading={save.isPending} onPress={() => submit(draft)} />
          <Button label={t('common.cancel')} variant="secondary" onPress={() => setDraft(null)} />
        </>
      )}
      <ErrorMessage error={save.error} />
    </Section>
  );
}

const PUSH_MESSAGES: Record<Exclude<PushResult, 'enabled'>, string> = {
  denied: 'settings.pushDenied',
  unsupported: 'settings.pushUnsupported',
  failed: 'settings.pushFailed',
};

function PushSection() {
  const { t } = useTranslation();
  const [enabled, setEnabled] = useState(false);
  const [busy, setBusy] = useState(false);
  const [problem, setProblem] = useState<Exclude<PushResult, 'enabled'> | null>(null);

  useEffect(() => {
    void isPushEnabled().then(setEnabled);
  }, []);

  if (!isPushSupported()) {
    return (
      <Section title={t('settings.push')}>
        <AppText variant="muted">{t('settings.pushUnsupported')}</AppText>
      </Section>
    );
  }

  const toggle = async (on: boolean) => {
    setBusy(true);
    setProblem(null);
    if (on) {
      const result = await enablePush();
      setEnabled(result === 'enabled');
      if (result !== 'enabled') setProblem(result);
    } else {
      await disablePush();
      setEnabled(false);
    }
    setBusy(false);
  };

  return (
    <Section title={t('settings.push')}>
      <View className="flex-row items-center justify-between gap-3">
        <AppText className="flex-1">{t('settings.push')}</AppText>
        <Switch accessibilityLabel={t('settings.push')} value={enabled} disabled={busy} onValueChange={(on) => void toggle(on)} />
      </View>
      {problem ? <Banner tone="warning" message={t(PUSH_MESSAGES[problem])} /> : null}
    </Section>
  );
}

function AccountSection() {
  const { t } = useTranslation();
  const remove = useDeleteAccount();
  const [password, setPassword] = useState('');
  const [leaving, setLeaving] = useState(false);

  const logout = async () => {
    setLeaving(true);
    // Stop pushes to this device for this account, then revoke the token.
    await disablePush().catch(() => undefined);
    await authApi.logout().catch(() => undefined);
    await useSession.getState().signOut();
  };

  return (
    <>
      <Section title={t('settings.logout')}>
        <TextLink label={t('settings.categories')} onPress={() => router.push('/categories')} />
        <Button label={t('settings.logout')} variant="secondary" loading={leaving} onPress={() => void logout()} />
      </Section>
      <Section title={t('settings.deleteAccount')}>
        <AppText variant="muted">{t('settings.deleteWarning')}</AppText>
        <TextField label={t('settings.deletePassword')} value={password} onChangeText={setPassword} secureTextEntry autoComplete="current-password" />
        <Button
          label={t('settings.deleteConfirm')}
          variant="danger"
          loading={remove.isPending}
          disabled={password === ''}
          onPress={() => remove.mutate(password)}
        />
        <ErrorMessage error={remove.error} />
      </Section>
    </>
  );
}

export default function SettingsScreen() {
  const me = useMe();

  if (!me.data) return me.isError ? <Screen><ErrorMessage error={me.error} /></Screen> : <Loading />;

  return (
    <Screen>
      <ProfileSection user={me.data} />
      <DefaultRemindersSection />
      <PushSection />
      <AccountSection />
    </Screen>
  );
}
```

```bash
cd ~/Sites/subs && docker compose up -d

```

In Chrome at `http://localhost:8081`, check each of these:
1. **Register** a new account. You land on an empty dashboard showing the "verify your email" banner. Mailpit at `http://localhost:8025` has the verification email.
2. **Add Netflix** at `12,99` EUR. "Saved as €12.99" appears. After saving, the push prompt opens. Turn it on and allow notifications.
3. **Dashboard** shows €12.99 per month and €155.88 per year, Netflix under Video Streaming, and the next payment in "Next 30 days".
4. **Change Settings → Main currency** to USD. The dashboard totals switch to USD.
5. **Set up a reminder that fires now:**
   - Open the subscription, tap Customize, and set the rule to 0 days before at the current time (the account's timezone), with Push and In-app selected.
   - Set the first payment date to today.
   - Run `docker compose exec php php artisan reminders:dispatch`.
   - Wait for Horizon (`http://localhost:8080/horizon`) to process the jobs.
   - Expect a browser notification, the inbox shows it with an unread dot, and the bell shows 1.
   - Clicking the notification opens `/subscriptions/<id>`.
6. **Offline check:** in DevTools set Network to Offline. The offline banner shows, cached screens stay visible, and Save buttons are disabled.
7. **Session expiry:** run `docker compose exec php php artisan tinker --execute="App\Models\User::latest('id')->first()->tokens()->delete();"`, then pull to refresh the subscriptions list. The app returns to the login screen.

If an iOS simulator is available, run `npx expo start --ios` and repeat checks 1–4 in Expo Go. Push shows "unsupported" there, as designed.

Write down each check that failed and fix it before the commit. A failing check is a bug in the task that owns it.
